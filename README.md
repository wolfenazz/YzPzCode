## ⚡ Why YzPzCode?

AI-assisted development usually turns into a shuffle between terminal tabs, agents, browsers, IDEs and one-off CLIs. **YzPzCode replaces the window juggling with one native command center.**

| Traditional workflow | With YzPzCode |
| :--- | :--- |
| 🪟 8+ disconnected terminal windows | 🖥️ **One native workspace** with custom layouts |
| 🔄 Constant `Alt+Tab` context switching | 🎛️ **Side-by-side terminal grid** of real PTY sessions |
| 🔌 Assistant panels locked inside external IDEs | 🧩 **Graphical extensions** embedded in the grid |
| ⚙️ Manual build scripts and run commands | ⚡ **Run & build** with 15+ ecosystems auto-detected |
| 🧩 External editor and file viewer | 📝 **Embedded editor** with a virtualized file tree and Git |
| 🌐 A separate browser for UI checks | 🔍 **In-app browser** with a visual inspector that prompts agents |
| 📱 A separate emulator window | 📲 **Android and iOS device window** with Flutter hot reload |
| 📄 Word, PowerPoint and a separate AI chat | ✍️ **Writing & Presentation studios** on the same AI CLIs |
| 🔑 Repetitive CLI install and auth checks | 🔐 **Detection, one-click install and auth tracking** |
| 🎨 Photoshop or Figma for quick edits | 🖌️ **Layered image editor** with blend modes |

##  Graphical Workspace Extensions

Run graphical coding assistants right next to your shells and agents, inside the workspace grid. Press **`Ctrl+Shift+X`** or click the Extensions icon in the header to open the catalog.

| Extension | Publisher | Description |
| :--- | :--- | :--- |
| **Google Antigravity** | Google | Google's official agentic assistant with chat, plans and code edits. |
| **Kilo Code** | Kilo | Code, plan and debug with Kilo's visual extension panel. |
| **Cline** | Cline | Autonomous coding assistant with plan/act modes and tool approval gates. |
| **OpenAI Codex** | OpenAI | OpenAI's coding extension with ChatGPT sign-in and code assistance. |
| **Claude Code** | Anthropic | Anthropic's visual coding assistant and conversation panel. |
| **Continue** | Continue | Open-source agent and code chat with cloud or local model backends. |
| **Amazon Q Developer** | AWS | Code chat and inline feature development with Amazon Q. |
| **Tabby** | TabbyML | Self-hosted coding assistant connected to a private Tabby server. |
| **Windsurf Plugin** | Windsurf | Codeium assistant with AI code chat and codebase index. |
| **Mistral Vibe** | Mistral AI | Mistral's visual coding agent with context, conversations and tools. |
| **Roo Code** | Roo Code | Cline-family agent with custom modes, multi-model support and per-step approvals. |
| **Qoder CN** | Alibaba Cloud | Alibaba Cloud's agentic coding assistant with chat and agent modes; requires sign-in. |
| **Augment** | Augment Code | Coding agent with a context engine built for large codebases; requires sign-in. |
| **Nexrall Code** | Nexrall | Autonomous coding agent with per-step approvals, checkpoints and MCP tools; requires an account. |

- 🎛️ **Side-by-side grid layouts**: panels mount inside the terminal grid with drag-and-drop reordering, interactive resizing, focus presets and split layouts.
- 📌 **Editor side dock**: dock a panel to the right of the editor (`Ctrl+Alt+B`) and move it between grid and dock without restarting it.
- 📨 **Prompt handoff**: send a browser-inspector selection or a UI reference straight into an assistant panel; the prompt is inserted and submitted, and the outcome shows on the panel header.
- 🌈 **Activity glow**: panels get the same working ring and finish effect as agent terminals.
- 📦 **Zero-config managed runtime**: a verified VSCodium `reh-web` runtime is provisioned with pinned SHA-256 digests and Open VSX packages. No VS Code or Node install needed.
- 🛡️ **Hardened sandboxing**: every assistant runs in an isolated child webview on its own `panel-<uuid>.localhost:<port>` origin with persistent storage, and cannot call Tauri host commands.
- 🔒 **Workspace trust & persistence**: trust approvals (`workspace-trust.json`) and IndexedDB workbench state (`workbench-state.json`) are kept per workspace.

See [the graphical workspace extensions documentation](docs/extensions.md) for architecture, runtime specifications and validation details.

##  Writing, Presentation & Sheets Studios

<div align="center">
  <img src="docs/readme/studios.svg" width="100%" alt="The Writing Studio with outline, paged report and assistant, and the Presentation Studio with filmstrip, canvas and design panel" />
</div>

<br />

Besides coding, the setup page's mode switch opens three document studios. They need no terminals or IDEs, run the AI through the CLIs you already have installed (Claude Code, Codex, Grok, Antigravity, OpenCode) in a headless runner, and save into one folder, `Documents/YzPzCode`, so reports, decks and workbooks are found again after a reinstall.

<table>
<tr>
<td width="50%" valign="top">

###  Writing Studio

- **30 report kinds**: pick a kind and answer one question in a single-box composer; attach files, paste material, add references
- **Streaming paged editor**: outline with live section status, tables, figures, citations and footnotes, with your reading place held while sections stream in
- **Assistant**: write the remaining sections, rewrite the selection or section, humanize or rewrite the whole document, with a review card for every change
- **Humanizer & lint**: naturalness score, stock-phrase, opener, rhythm and em-dash checks, optional highlighting
- **Design panel**: six templates, fonts, colours, page and structure controls, and **Restyle with AI** with one-click undo
- **Real web photos**: openly licensed images from Openverse, Unsplash or Pexels with credit, never AI images
- **Export**: PDF, Word `.docx`, standalone HTML; import existing `.docx`

</td>
<td width="50%" valign="top">

###  Presentation Studio

- **AI-designed decks**: describe the deck; the AI invents a design system, writes a storyline with per-page briefs, then draws every slide as SVG
- **Real slide editor**: select, marquee, drag with guides, resize, type in place, shapes, pictures, tables, groups, format bar
- **Edit with AI**: change one slide, several or the whole deck; every change is a proposal with Keep or Discard, batches are reviewed side by side
- **Animation**: entrance, emphasis and exit effects, click order, paragraph builds and AI-designed motion
- **Pictures**: drop files or folders, mention paths in the prompt, or add real web photos
- **PowerPoint round trip**: import `.pptx` as PowerPoint draws it; export editable PowerPoint, "exact look" PowerPoint, PDF, PNG and HTML

###  Arabic and right-to-left, first-class

Arabic, Hebrew, Persian and Urdu work in both studios: paragraph direction follows the text, printed labels (Chapter, Table, Figure, Contents…) follow the document language, Word and PowerPoint exports write real bidirectional paragraphs, and a catalog of about 150 fonts (Latin and Arabic, with bundled `@fontsource` faces) feeds every font picker.

##  Mobile Device Window

<div align="center">
  <img src="docs/readme/devices.svg" width="100%" alt="An Android emulator and an iOS simulator streamed into the workspace next to a Flutter project with hot reload" />
</div>

<br />

A device window slides in from the right edge of every workspace view (terminal, extensions, editor, browser) and pushes the view aside instead of floating over it, so native webviews are never covered.

- 🤖 **Embedded Android emulator**: create and start AVDs from the app; the screen streams into the window (gRPC frames through the shared `frame-codec` crate) with touch, multi-touch, keyboard, scroll, rotation, skins and screenshots.
- 🍎 **iOS Simulator (macOS)**: discovery and lifecycle through `simctl`, screen and input through `idb_companion`. Off macOS it is reported as unavailable.
- 🐦 **Flutter run bar**: run the workspace's app on the chosen device with hot reload (also on `.dart` save), hot restart and a live log.
- 🛠️ **Guided setup**: **Settings → Environment** inspects the Flutter, Android (and Xcode on macOS) toolchain and offers one-click fixes for missing SDK parts and hardware acceleration.

##  Local Narration

<div align="center">
  <img src="docs/readme/narration.svg" width="100%" alt="A waveform and the three local voices SILMA, Lahgtna-Chatterbox and Kokoro" />
</div>

<br />

Reports and slides can be read aloud without sending text to a cloud service. Narration runs in a managed local Python environment and downloads models on demand (**Settings → Narration**).

| Model | Languages | Size | Notes |
| :--- | :---: | :---: | :--- |
| **SILMA TTS v1** (default) | Arabic + English | ~2.5 GB | Balanced bilingual voice, Tashkeel-aware |
| **Lahgtna-Chatterbox** | Arabic | ~1.5 GB | Egyptian, Saudi, Moroccan and Iraqi dialects |
| **Kokoro-82M** | English | ~350 MB | Very fast, suited to long reports |

Language is detected from the text, speed is 0.75× / 1× / 1.25×, and synthesized audio is cached on disk (LRU, 500 MB cap). Narrate the selection or a section in the Writing Studio, and slides in the Presentation Studio and presenter mode.

##  Application Run & Build System

Launch, build and debug your applications with zero configuration. Project manifests and runnable entry points are discovered across 15+ ecosystems, right inside terminal headers.

<div align="center">

| Ecosystem | Detection & execution |
| :--- | :--- |
| **Python** | Detects `.py` scripts, `main.py`, `app.py`, Django `manage.py`, Flask and FastAPI servers. Prefers a local `.venv`, `venv` or system Python. |
| **JavaScript / TypeScript** | Discovers `package.json` dev, start and build scripts. Invokes `npm`, `pnpm`, `Yarn` or `Bun` from the lockfile. |
| **Rust / Go / Flutter** | Cargo (`cargo run`), Go modules (`go run .`) and Flutter project manifests (`flutter run`). |
| **C / C++** | Finds sources with `main()`, compiles via GCC or Clang into `.yzpz-run/` and runs the binary. |
| **CMake** | Reads the CMake File API to locate Debug targets in `.yzpz-build/`, building before launch. |
| **C# (.NET)** | Discovers and runs executable `.csproj` files in projects and solutions with the .NET SDK. |
| **Java** | Single-file source execution via JDK 11+ and project launch configurations. |
| **Ruby, PHP, Dart, Swift, Lua, Perl, R** | Runs entry points with installed interpreters; Rails and Laravel manifest commands. |

</div>

- ▶️ **One-click run & build** from the terminal header with instant target switching.
- 💬 **Interactive stdin console**: send input to running programs (`input()`, `scanf`, `Console.ReadLine()`) from the terminal input bar.
- 🌐 **Dev-server auto-discovery**: localhost URLs in terminal output become a 1-click preview in the browser bar.
- ⚙️ **Custom run configurations**: commands, environment variables, arguments and working directories in **Settings → Application runs**, global or per workspace.

See [the application runs guide](docs/application-runs.md) for configuration schemas, multi-target switching and compiler details.

##  Core Features

<details open>
<summary><b> Multi-agent terminal grid</b></summary>

<br />

- **Real PTY backend**: xterm.js 6 frontend powered by Rust's `portable-pty`
- **Managed commands**: non-interactive and background tasks with PID, exit code and live output streaming
- **Terminal mouse modes**: full xterm mouse reporting (click, drag, any-event, application tracking) for TUIs
- **Hardware-accelerated rendering**: canvas/WebGL pipeline with dirty-rectangle updates for low latency
- **Workspace scoping**: sessions are isolated per project workspace
- **Spawn dialog**: searchable, grouped by shells, primary agents, additional agents and SaaS tool CLIs, with live status badges
- **Agent activity indicator**: idle → working → done per pane, with a working ring, finish effect and optional completion sound
- **Dynamic layouts**: layouts adapt to the number of panes, with drag-reordering and a layout picker
- **Editor terminal panel**: a VS Code-style terminal under the editor (<kbd>Ctrl</kbd>+<kbd>`</kbd> toggles, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>`</kbd> opens a new shell) with a shell picker and per-workspace scrollback
- **External terminal tiling**: native consoles (Windows Terminal, macOS Terminal, Linux) with auto-tiling

</details>

<details>
<summary><b> Editor, previews & source control</b></summary>

<br />

- **Multi-tab workspace**: split views and tab management (close others / right / saved)
- **Syntax highlighting & minimap**: Monaco and CodeMirror engines
- **Rich previews**: Markdown, PDF, CSV, Excel (`.xlsx`), Word (`.docx`) and Draw.io diagrams
- **Media & binary previews**: audio (waveform, transport, speed, loop) and video streamed with HTTP range support, plus a hex view for other binary files
- **Transactional file sync**: a recursive watcher (`notify`) with debounced sync keeps open tabs in step with external IDEs and agents
- **Integrated Git**: branch switching, diff stats, stage/unstage files or hunks, discard, commit and remote sync
- **OS clipboard in the explorer**: copy, cut and paste files (and clipboard images) between the explorer and the operating system, with per-item outcomes and undo
- **Open in terminal**: any folder into a new integrated pane or an external terminal

</details>

<details>
<summary><b> In-app browser & visual inspector</b></summary>

<br />

- **Quick prompt card**: pick an element and a small card appears beside it: choose an agent or extension panel, type one line, send. **More controls** opens the full inspector with the draft carried over
- **Deep element inspector**: computed CSS, pseudo-elements, box model and DOM hierarchy
- **Style picker & generator**: capture styles, generate atomic CSS classes, apply with a full undo stack
- **UI element capture**: structure, layout, typography, pseudo-elements, assets and design intent as reusable UI references
- **Tabs, start page & device emulation**: per-workspace tabs, a start page listing live dev servers, device presets and custom viewports
- **Dev-server integration**: 1-click preview when a dev server emits a local URL

</details>

<details>
<summary><b> AI designer & layered image editor</b></summary>

<br />

- **Prompt-to-UI generator**: responsive HTML/CSS/JS interfaces from natural language
- **Layered canvas**: raster, vector, text and shape layers powered by Konva
- **16 blend modes**, opacity, rotation, masking, marquee and lasso selections, history
- **Export**: PNG, JPG, WebP, SVG, GIF, BMP, AVIF, TIFF

</details>

<details>
<summary><b> Customization</b></summary>

<br />

- 🌗 **Dark / light modes** with dynamic theming across the whole UI
- 🎨 **8 accent colours**: Default, Blue, Purple, Green, Orange, Red, Pink, Cyan
- 🧪 **Custom theme engine**: build a theme from 9 colours, a light/dark base and a radius, with WCAG contrast checks, 40+ presets and JSON import/export (**Settings → Appearance → Custom themes**)
- 🌌 **Animated backgrounds**: aurora, galaxy and light rays for the setup screen and workspaces, with intensity, speed, blur and opacity controls
- 💎 **Modern app chrome**: view switcher tabs, status indicators and real-time process monitoring in the footer
- 📐 **3 density presets**: Compact, Comfortable, Spacious
- ⌨️ **Terminal styling**: fonts, ligatures, cursor styles, mouse tracking and opacity
- ♿ **Accessibility**: animation disable toggle (reduced motion), custom cursor toggle

</details>

##  Download & Installation

### Option 1: Pre-built binaries (recommended)

Grab the latest installer from the **[Releases page](https://github.com/wolfenazz/YzPzCode/releases/latest)**:

| Platform | Package format | Architecture |
| :--- | :--- | :--- |
| **🪟 Windows** | `.msi` / `.exe` installer | x86_64 |
| **🍎 macOS** | `.dmg` installer | Apple Silicon (`aarch64`) & Intel (`x86_64`) |
| **🐧 Linux** | `.deb` / `.AppImage` | x86_64 |

> [!TIP]
> **macOS**: for an unsigned build, open with **Right Click → Open**, or allow it under *System Settings → Privacy & Security → Open Anyway*.

### Option 2: Build from source

**Prerequisites:** Node.js `22.x` or higher, the latest stable Rust toolchain (`rustup update stable`), and C++ build tools (Visual Studio Build Tools on Windows, Xcode CLI Tools on macOS, `build-essential` on Linux).

```bash
git clone https://github.com/wolfenazz/YzPzCode.git
cd YzPzCode/app

npm install            # frontend dependencies
npm run tauri dev      # development mode (port 8745)
npm run tauri build    # production installers
```

The compiled binaries land in `app/src-tauri/target/release/bundle/`.

##  Security & Privacy

YzPzCode is built **local-first**:

- 🛡️ **Your code stays local**: project files and source code are never uploaded to third-party servers by YzPzCode itself.
- 🔑 **Locally stored secrets**: API keys and tokens live only on your machine.
- 📡 **Direct provider connections**: requests go straight to the official endpoints of the providers you configure.
- 🔊 **On-device narration**: text-to-speech models run locally; nothing is sent to a speech service.
