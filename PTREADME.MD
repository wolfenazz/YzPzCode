## ⚡ Por que o YzPzCode?

O desenvolvimento assistido por IA geralmente vira uma alternância entre abas de terminal, agentes, navegadores, IDEs e CLIs isoladas. **O YzPzCode substitui essa dança de janelas por um centro de comando nativo.**

| Fluxo tradicional | Com o YzPzCode |
| :--- | :--- |
| 🪟 8+ janelas de terminal desconectadas | 🖥️ **Um workspace nativo** com layouts personalizados |
| 🔄 Troca constante de contexto com `Alt+Tab` | 🎛️ **Grade de terminais lado a lado** com sessões PTY reais |
| 🔌 Painéis de assistentes presos dentro de IDEs externas | 🧩 **Extensões gráficas** incorporadas à grade |
| ⚙️ Scripts de build e comandos de execução manuais | ⚡ **Execução e build** com mais de 15 ecossistemas detectados automaticamente |
| 🧩 Editor e visualizador de arquivos externos | 📝 **Editor integrado** com árvore de arquivos virtualizada e Git |
| 🌐 Um navegador separado para verificar a UI | 🔍 **Navegador integrado** com inspector visual que envia prompts aos agentes |
| 📱 Uma janela de emulador separada | 📲 **Janela de dispositivo Android e iOS** com hot reload do Flutter |
| 📄 Word, PowerPoint e um chat de IA separado | ✍️ **Estúdios de Escrita e Apresentações** usando as mesmas CLIs de IA |
| 🔑 Instalações de CLI e verificações de autenticação repetitivas | 🔐 **Detecção, instalação com um clique e acompanhamento da autenticação** |
| 🎨 Photoshop ou Figma para edições rápidas | 🖌️ **Editor de imagens em camadas** com modos de mesclagem |

##  Extensões gráficas do workspace

Execute assistentes gráficos de programação ao lado dos seus shells e agentes, dentro da grade do workspace. Pressione **`Ctrl+Shift+X`** ou clique no ícone de extensões no cabeçalho para abrir o catálogo.

| Extensão | Publicador | Descrição |
| :--- | :--- | :--- |
| **Google Antigravity** | Google | Assistente agentivo oficial do Google, com chat, planos e edições de código. |
| **Kilo Code** | Kilo | Programe, planeje e depure com o painel visual de extensão do Kilo. |
| **Cline** | Cline | Assistente autônomo de programação com modos plan/act e etapas de aprovação de ferramentas. |
| **OpenAI Codex** | OpenAI | Extensão de programação da OpenAI com login do ChatGPT e assistência de código. |
| **Claude Code** | Anthropic | Assistente visual de programação da Anthropic e painel de conversas. |
| **Continue** | Continue | Agente open source e chat de código com backends de modelos locais ou em nuvem. |
| **Amazon Q Developer** | AWS | Chat de código e desenvolvimento de recursos inline com o Amazon Q. |
| **Tabby** | TabbyML | Assistente de programação self-hosted conectado a um servidor Tabby privado. |
| **Windsurf Plugin** | Windsurf | Assistente Codeium com chat de código por IA e índice da base de código. |
| **Mistral Vibe** | Mistral AI | Agente visual de programação da Mistral com contexto, conversas e ferramentas. |
| **Roo Code** | Roo Code | Agente da família Cline com modos personalizados, suporte a vários modelos e aprovações por etapa. |
| **Qoder CN** | Alibaba Cloud | Assistente agentivo de programação da Alibaba Cloud com modos de chat e agente; requer login. |
| **Augment** | Augment Code | Agente de programação com mecanismo de contexto criado para bases de código grandes; requer login. |
| **Nexrall Code** | Nexrall | Agente autônomo de programação com aprovações por etapa, checkpoints e ferramentas MCP; requer uma conta. |

- 🎛️ **Layouts de grade lado a lado**: os painéis são montados dentro da grade de terminais, com reordenação por arrastar e soltar, redimensionamento interativo, predefinições de foco e layouts divididos.
- 📌 **Dock lateral do editor**: fixe um painel à direita do editor (`Ctrl+Alt+B`) e mova-o entre a grade e o dock sem reiniciá-lo.
- 📨 **Transferência de prompt**: envie uma seleção do inspector do navegador ou uma referência de UI diretamente para um painel de assistente; o prompt é inserido e enviado, e o resultado aparece no cabeçalho do painel.
- 🌈 **Brilho de atividade**: os painéis recebem o mesmo anel de trabalho e efeito de conclusão dos terminais de agentes.
- 📦 **Runtime gerenciado sem configuração**: um runtime VSCodium `reh-web` verificado é provisionado com digests SHA-256 fixados e pacotes Open VSX. Não é necessário instalar VS Code ou Node.
- 🛡️ **Sandbox reforçado**: cada assistente é executado em um webview filho isolado, em sua própria origem `panel-<uuid>.localhost:<port>` com armazenamento persistente, e não pode chamar comandos do host Tauri.
- 🔒 **Confiança e persistência do workspace**: as aprovações de confiança (`workspace-trust.json`) e o estado do workbench no IndexedDB (`workbench-state.json`) são mantidos por workspace.

Veja [a documentação das extensões gráficas do workspace](docs/extensions.md) para conhecer a arquitetura, as especificações do runtime e os detalhes de validação.

##  Estúdios de escrita, apresentações e planilhas

<div align="center">
  <img src="docs/readme/studios.svg" width="100%" alt="O Writing Studio com outline, relatório paginado e assistente, e o Presentation Studio com filmstrip, canvas e painel de design" />
</div>

<br />

Além da programação, o seletor de modo da página de configuração abre três estúdios de documentos. Eles não precisam de terminais nem IDEs, executam a IA pelas CLIs que você já instalou (Claude Code, Codex, Grok, Antigravity, OpenCode) em um runner headless e salvam tudo em uma pasta, `Documents/YzPzCode`, para que relatórios, apresentações e planilhas sejam encontrados novamente após uma reinstalação.

<table>
<tr>
<td width="50%" valign="top">

###  Writing Studio

- **30 tipos de relatório**: escolha um tipo e responda a uma pergunta em um composer de caixa única; anexe arquivos, cole material e adicione referências
- **Editor paginado com streaming**: outline com status de seção ao vivo, tabelas, figuras, citações e notas de rodapé, mantendo sua posição de leitura enquanto as seções chegam
- **Assistente**: escreva as seções restantes, reescreva a seleção ou seção, humanize ou reescreva o documento inteiro, com um card de revisão para cada alteração
- **Humanizer e lint**: pontuação de naturalidade, verificações de frases prontas, aberturas, ritmo e travessões, com destaque opcional
- **Painel de design**: seis templates, fontes, cores, controles de página e estrutura, além de **Restyle with AI** com desfazer em um clique
- **Fotos reais da web**: imagens com licença aberta do Openverse, Unsplash ou Pexels, com crédito, nunca imagens geradas por IA
- **Exportação**: PDF, Word `.docx`, HTML independente; importação de `.docx` existente

</td>
<td width="50%" valign="top">

###  Presentation Studio

- **Apresentações projetadas por IA**: descreva a apresentação; a IA cria um sistema de design, escreve uma narrativa com briefs por página e então desenha cada slide como SVG
- **Editor de slides real**: selecionar, marquee, arrastar com guias, redimensionar, digitar no local, formas, imagens, tabelas, grupos e barra de formatação
- **Editar com IA**: altere um slide, vários ou a apresentação inteira; cada alteração é uma proposta com Keep ou Discard, e os lotes são revisados lado a lado
- **Animação**: efeitos de entrada, ênfase e saída, ordem de cliques, construção de parágrafos e movimento projetado por IA
- **Imagens**: solte arquivos ou pastas, mencione caminhos no prompt ou adicione fotos reais da web
- **Ida e volta com PowerPoint**: importe `.pptx` como o PowerPoint o desenha; exporte PowerPoint editável, PowerPoint com "visual exato", PDF, PNG e HTML
- **Modo de apresentação**: exibição em tela cheia, visão do apresentador com notas, cronômetro e ritmo, transições e narração

</td>
</tr>
</table>

###  Árabe e escrita da direita para a esquerda, com suporte de primeira classe

Árabe, hebraico, persa e urdu funcionam nos dois estúdios: a direção dos parágrafos acompanha o texto, os rótulos impressos (Chapter, Table, Figure, Contents…) seguem o idioma do documento, as exportações para Word e PowerPoint escrevem parágrafos bidirecionais reais, e um catálogo com cerca de 150 fontes (latinas e árabes, com faces `@fontsource` incluídas) alimenta todos os seletores de fonte.

##  Janela de dispositivo móvel

<div align="center">
  <img src="docs/readme/devices.svg" width="100%" alt="Um emulador Android e um simulador iOS exibidos no workspace ao lado de um projeto Flutter com hot reload" />
</div>

<br />

Uma janela de dispositivo desliza pela borda direita de cada visualização do workspace (terminal, extensões, editor, navegador) e desloca a visualização para o lado em vez de flutuar sobre ela, para que webviews nativos nunca sejam encobertos.

- 🤖 **Emulador Android integrado**: crie e inicie AVDs pelo app; a tela é exibida na janela (frames gRPC pelo crate compartilhado `frame-codec`) com toque, multitoque, teclado, rolagem, rotação, skins e capturas de tela.
- 🍎 **Simulador iOS (macOS)**: descoberta e ciclo de vida por meio do `simctl`, tela e entrada por meio do `idb_companion`. Fora do macOS, é reportado como indisponível.
- 🐦 **Barra de execução do Flutter**: execute o app do workspace no dispositivo escolhido com hot reload (também ao salvar `.dart`), hot restart e log ao vivo.
- 🛠️ **Configuração guiada**: **Settings → Environment** inspeciona o toolchain do Flutter, Android (e Xcode no macOS) e oferece correções com um clique para partes ausentes do SDK e aceleração de hardware.

##  Narração local

<div align="center">
  <img src="docs/readme/narration.svg" width="100%" alt="Uma forma de onda e as três vozes locais SILMA, Lahgtna-Chatterbox e Kokoro" />
</div>

<br />

Relatórios e slides podem ser lidos em voz alta sem enviar texto para um serviço na nuvem. A narração é executada em um ambiente Python local gerenciado e baixa os modelos sob demanda (**Settings → Narration**).

| Modelo | Idiomas | Tamanho | Observações |
| :--- | :---: | :---: | :--- |
| **SILMA TTS v1** (padrão) | Árabe + inglês | ~2.5 GB | Voz bilíngue equilibrada, ciente de Tashkeel |
| **Lahgtna-Chatterbox** | Árabe | ~1.5 GB | Dialetos egípcio, saudita, marroquino e iraquiano |
| **Kokoro-82M** | Inglês | ~350 MB | Muito rápido, adequado para relatórios longos |

O idioma é detectado a partir do texto, a velocidade é 0.75× / 1× / 1.25×, e o áudio sintetizado é armazenado em cache no disco (LRU, teto de 500 MB). Narre a seleção ou uma seção no Writing Studio, e os slides no Presentation Studio e no modo de apresentação.

##  Sistema de execução e build de aplicações

Inicie, faça build e depure suas aplicações sem configuração. Manifestos de projetos e pontos de entrada executáveis são descobertos em mais de 15 ecossistemas, diretamente nos cabeçalhos dos terminais.

<div align="center">

| Ecossistema | Detecção e execução |
| :--- | :--- |
| **Python** | Detecta scripts `.py`, `main.py`, `app.py`, `manage.py` do Django e servidores Flask e FastAPI. Prefere um Python local em `.venv`, `venv` ou o Python do sistema. |
| **JavaScript / TypeScript** | Descobre scripts de desenvolvimento, inicialização e build em `package.json`. Invoca `npm`, `pnpm`, `Yarn` ou `Bun` a partir do lockfile. |
| **Rust / Go / Flutter** | Cargo (`cargo run`), módulos Go (`go run .`) e manifestos de projeto Flutter (`flutter run`). |
| **C / C++** | Encontra fontes com `main()`, compila via GCC ou Clang em `.yzpz-run/` e executa o binário. |
| **CMake** | Lê a CMake File API para localizar targets Debug em `.yzpz-build/`, compilando antes da inicialização. |
| **C# (.NET)** | Descobre e executa arquivos `.csproj` executáveis em projetos e soluções com o SDK do .NET. |
| **Java** | Execução de fonte em arquivo único via JDK 11+ e configurações de inicialização de projetos. |
| **Ruby, PHP, Dart, Swift, Lua, Perl, R** | Executa pontos de entrada com os interpretadores instalados; comandos de manifesto do Rails e Laravel. |

</div>

- ▶️ **Execução e build com um clique** no cabeçalho do terminal, com troca instantânea de target.
- 💬 **Console interativo de stdin**: envie entrada para programas em execução (`input()`, `scanf`, `Console.ReadLine()`) pela barra de entrada do terminal.
- 🌐 **Descoberta automática de dev server**: URLs localhost na saída do terminal se tornam uma prévia com um clique na barra do navegador.
- ⚙️ **Configurações de execução personalizadas**: comandos, variáveis de ambiente, argumentos e diretórios de trabalho em **Settings → Application runs**, globalmente ou por workspace.

Veja [o guia de execuções de aplicações](docs/application-runs.md) para esquemas de configuração, troca entre vários targets e detalhes do compilador.

##  Recursos principais

<details open>
<summary><b> Grade de terminais multiagente</b></summary>

<br />

- **Backend PTY real**: frontend xterm.js 6 alimentado pelo `portable-pty` do Rust
- **Comandos gerenciados**: tarefas não interativas e em segundo plano com PID, código de saída e streaming de saída ao vivo
- **Modos de mouse do terminal**: suporte completo a mouse do xterm (clique, arrastar, qualquer evento, rastreamento de aplicação) para TUIs
- **Renderização acelerada por hardware**: pipeline canvas/WebGL com atualizações de retângulos sujos para baixa latência
- **Escopo por workspace**: sessões são isoladas por workspace de projeto
- **Diálogo de criação**: pesquisável, agrupado por shells, agentes principais, agentes adicionais e Tool CLIs SaaS, com badges de status ao vivo
- **Indicador de atividade do agente**: ocioso → trabalhando → concluído por painel, com anel de trabalho, efeito de conclusão e som opcional
- **Layouts dinâmicos**: os layouts se adaptam ao número de painéis, com reordenação por arrastar e seletor de layout
- **Painel de terminal do editor**: terminal no estilo VS Code sob o editor (<kbd>Ctrl</kbd>+<kbd>`</kbd> alterna, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>`</kbd> abre um novo shell), com seletor de shell e scrollback por workspace
- **Organização de terminais externos**: consoles nativos (Windows Terminal, macOS Terminal, Linux) com organização automática

</details>

<details>
<summary><b> Editor, prévias e controle de código-fonte</b></summary>

<br />

- **Workspace com várias abas**: visualizações divididas e gerenciamento de abas (fechar outras / à direita / salvas)
- **Destaque de sintaxe e minimap**: engines Monaco e CodeMirror
- **Pré-visualizações avançadas**: Markdown, PDF, CSV, Excel (`.xlsx`), Word (`.docx`) e diagramas Draw.io
- **Pré-visualizações de mídia e binários**: áudio (forma de onda, transporte, velocidade, loop) e vídeo exibido com suporte a HTTP range, além de uma visualização hexadecimal para outros arquivos binários
- **Sincronização transacional de arquivos**: um watcher recursivo (`notify`) com sincronização com debounce mantém as abas abertas alinhadas com IDEs e agentes externos

##  Download e instalação

### Opção 1: Binários pré-compilados (recomendado)

Baixe o instalador mais recente na **[página de Releases](https://github.com/wolfenazz/YzPzCode/releases/latest)**:

| Plataforma | Formato do pacote | Arquitetura |
| :--- | :--- | :--- |
| **🪟 Windows** | instalador `.msi` / `.exe` | x86_64 |
| **🍎 macOS** | instalador `.dmg` | Apple Silicon (`aarch64`) e Intel (`x86_64`) |
| **🐧 Linux** | `.deb` / `.AppImage` | x86_64 |

> [!TIP]
> **macOS**: para um build não assinado, abra com **Clique direito → Abrir**, ou permita em *Ajustes do Sistema → Privacidade e Segurança → Abrir mesmo assim*.

### Opção 2: Compilar a partir do código-fonte

**Pré-requisitos:** Node.js `22.x` ou superior, o toolchain Rust estável mais recente (`rustup update stable`) e ferramentas de build C++ (Visual Studio Build Tools no Windows, Xcode CLI Tools no macOS, `build-essential` no Linux).

```bash
git clone https://github.com/wolfenazz/YzPzCode.git
cd YzPzCode/app

npm install            # dependências do frontend
npm run tauri dev      # modo de desenvolvimento (porta 8745)
npm run tauri build    # instaladores de produção
```

Os binários compilados são colocados em `app/src-tauri/target/release/bundle/`.

##  Segurança e privacidade

O YzPzCode foi criado com uma abordagem **local-first**:

- 🛡️ **Seu código permanece local**: arquivos de projeto e código-fonte nunca são enviados a servidores de terceiros pelo próprio YzPzCode.
- 🔑 **Segredos armazenados localmente**: chaves de API e tokens ficam somente na sua máquina.
- 📡 **Conexões diretas com provedores**: as solicitações vão diretamente para os endpoints oficiais dos provedores que você configurar.
- 🔊 **Narração no dispositivo**: os modelos de conversão de texto em fala são executados localmente; nada é enviado a um serviço de voz.
